5. Cloud Deployment Guide (Render.com)

  1. Log into Render.com with GitHub and select New Web Service.
  2. Connect the repository rt2407-08/The_Assignment_Plagiarism.
  3. Configure:
    • Root Directory: backend
    • Build Command: npm install
    • Start Command: node server.js
  4. Add the environment variables:
    • PORT: 5000
    • MONGODB_URI: mongodb+srv://rt-2007:Shrutu2011@cluster0.g6nere2.mongodb.net/VeriText?retryWrites=true&w=majority
    • JWT_SECRET: veritext_super_secret_jwt_key_2026

  6. In frontend/src/services/api.js, replace http://127.0.0.1:5000 with your live Render URL.
